File Format Instructions

Your file should have tickers in one column and weights (%) in another. The parser is flexible:

  • Column headers can be named anything (Ticker, Symbol, Stock, etc.) — or you can skip headers entirely
  • Weights can be percentages (25%) or decimals (0.25) — both are auto-detected
  • Extra columns are ignored — only the ticker and weight columns are used
  • For CSV: comma, tab, or semicolon delimiters all work
Example:
AB
AAPL25
MSFT25
NVDA20
JPM15
XOM15
